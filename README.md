Code for the YFV vaccination analysis (airr_yfv19).
01.ipynb — Raw data, sequencing depth, and unique clonotypes at Day 0 and Day 15.
02.ipynb — Fisher’s exact test on CDR3nt (q < 0.05, FC > 4) and volcano plots.
03.ipynb — Pogorelyy probabilistic model: noise modeling, Day 0 vs Day 15 comparison, and model-positive clonotypes.
04.ipynb — Fisher vs. model: overlap, Jaccard index, and visualization.
05.ipynb — CDR3aa clustering (Hamming ≤ 1) and sequence logos.
06.ipynb — V/J gene and short motif enrichment analysis.
07.ipynb — Exact matches between Fisher-positive CDR3aa and YFV-associated TCRs.
08.ipynb — YFV/CMV reference sets and enrichment analysis (OR) against the same-donor background.
09.ipynb — CDR3aa sharing across donors: monozygotic twins vs. unrelated donors.
